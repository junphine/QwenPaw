# P 插件 v5.5.0 — 场景系统 + 道具背包 + 任务系统

## 🎉 新增功能

### 1. 🎭 场景系统 (Scene System)
**8种精美场景主题，一键切换聊天室氛围：**

| 场景 | 图标 | 氛围 | 背景风格 |
|------|------|------|----------|
| 默认 | 💬 | 清新明亮 | 浅色渐变 |
| 迷雾小镇 | 🏛️ | 神秘悬疑 | 深蓝紫渐变 |
| 灯塔 | 🗼 | 孤独警觉 | 深海蓝渐变 |
| 雾灯咖啡馆 | ☕ | 温暖舒适 | 咖啡棕渐变 |
| 诊所 | 🩺 | 神秘不安 | 冷灰蓝渐变 |
| 镇公所 | 🏛️ | 威严紧张 | 深灰蓝渐变 |
| 迷雾森林 | 🌲 | 危险未知 | 深绿渐变 |
| 午夜时分 | 🌙 | 恐怖秘密 | 深紫黑渐变 |

**API端点：**
- `GET /scenes` — 列出所有场景
- `GET /rooms/{room_id}/scene` — 获取当前场景
- `PUT /rooms/{room_id}/scene` — 切换场景（房主权限）

**前端功能：**
- 房间标题显示当前场景图标+名称
- 点击场景标签打开场景选择器
- 场景切换实时广播给所有成员
- 支持暗色/亮色主题适配

### 2. 🎒 道具背包系统 (Inventory System)
**三类道具，丰富游戏体验：**

- 🔍 **线索** — 推进剧情的关键信息（绿色背景）
- 📦 **道具** — 可在特定场景使用的物品（蓝色背景）
- 🏆 **成就** — 完成目标的纪念（黄色背景）

**API端点：**
- `GET /rooms/{room_id}/inventory/{user_id}` — 获取背包
- `POST /rooms/{room_id}/inventory/{user_id}/add` — 添加道具

**前端功能：**
- 顶部工具栏显示「🎒 背包」按钮
- 弹窗展示三类道具分类
- 每个道具显示图标、名称、描述、获得时间

### 3. 📜 任务系统 (Quest System)
**追踪游戏进度：**

- ⏳ **进行中任务** — 显示进度百分比
- ✅ **已完成任务** — 显示完成时间

**API端点：**
- `GET /rooms/{room_id}/quests/{user_id}` — 获取任务列表
- `POST /rooms/{room_id}/quests/{user_id}/accept` — 接受任务

**前端功能：**
- 顶部工具栏显示「📜 任务」按钮
- 弹窗展示进行中和已完成任务
- 任务卡片显示标题、描述、进度

### 4. 🎮 增强的游戏智能体
**游戏大师智能体升级：**

新增系统提示词支持：
- 场景感知 — 根据当前场景调整描述
- 道具奖励 — 可触发给予玩家道具
- 任务发布 — 可给玩家发布新任务
- 好感度追踪 — 更精细的好感度管理

**奖励格式（智能体回复中可包含）：**
```
[REWARD]
type: clue|item|achievement
name: 奖励名称
icon: emoji
description: 详细描述
```

**任务格式：**
```
[QUEST]
title: 任务标题
description: 任务描述
hint: 完成提示
```

## 🎮 游戏可玩性提升

### 沉浸式体验
- **场景切换**：进入不同地点自动切换背景和氛围
- **视觉反馈**：每个场景独特的配色和卡片样式
- **动态公告**：游戏指南、剧情提示实时显示

### 收集要素
- **线索收集**：与NPC对话解锁秘密
- **道具获取**：完成任务获得实用道具
- **成就系统**：记录游戏里程碑

### 进度追踪
- **任务列表**：清晰显示当前目标和进度
- **好感度**：与NPC关系可视化
- **章节推进**：剧情发展一目了然

## 🚀 使用流程

1. **进入游戏房间**
   - 显示「一键安装游戏智能体」提示
   - 点击安装5个NPC智能体

2. **开始游戏**
   - 阅读公告栏游戏指南
   - 查看背包（初始为空）
   - 查看任务列表（初始为空）

3. **与NPC互动**
   - @NPC名字开始对话
   - 提升好感度解锁秘密
   - 获得线索和道具

4. **场景探索**
   - 房主可切换场景改变氛围
   - 不同场景触发不同剧情
   - 午夜场景可能触发特殊事件

5. **完成任务**
   - 游戏大师发布任务
   - 收集线索推进剧情
   - 获得成就奖励
