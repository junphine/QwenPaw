## 🚀 安装步骤

### 1. 复制到插件目录
```bash
# 将 p_plugin 文件夹复制到 QwenPaw 插件目录
C:\Users\Administrator\.qwenpaw\plugins\p_plugin\
```

### 2. 重启 QwenPaw
- 完全关闭 QwenPaw
- 重新启动

### 3. 验证双显示模式
- [ ] **应用栏目** — 打开"应用"页面，看到 P 群聊卡片
- [ ] **侧边栏菜单** — 左侧"设置"分组，看到 P 群聊 v5.5.1
- [ ] **点击跳转** — 点击卡片或菜单都能正常打开插件
