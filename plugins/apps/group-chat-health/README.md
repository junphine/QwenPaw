# Group Chat

[English](./README.en.md) | 简体中文

Group Chat 是一款面向 QwenPaw 的多智能体群聊插件。它会读取当前已启用的 Agent，让你将不同角色加入同一个群聊，共享对话上下文，并通过智能分配和 `@` 完成协作。

## 能做什么

- **自由组群**：从 QwenPaw 中已有且已启用的 Agent 里选择一位或多位成员。
- **智能分配**：普通消息会根据成员的名称、描述和最近上下文，邀请合适的成员回答。
- **指定成员**：输入 `@` 或点击快捷成员，一条消息可以按顺序提及多位 Agent。
- **成员接力**：Agent 可以在回复中 `@` 其他群成员，让对方继续补充。
- **完整群聊体验**：支持引用、附件、失败重试和持久化聊天记录。
- **主动参与**：可按需开启，并可设置静默时段、每日上限和冷却时间。

群成员会继续使用各自原有的人设、模型、知识、技能、工具权限和工作区；插件只负责组织群聊，不会改变成员本身的能力配置。

## 安装

1. 在 QwenPaw 左侧栏进入 **扩展 → 应用市场**。
2. 搜索 **Group Chat**。
3. 找到对应应用并点击安装。
4. 安装完成后打开 **Group Chat**。

## 怎么使用

1. 点击新建群聊，填写群聊名称。
2. 选择一位或多位已启用的 Agent 作为群成员并保存。
3. 直接发送消息，由系统自动选择合适的成员回复。
4. 需要明确分工时，输入 `@成员名称`，或点击输入框下方的快捷成员。
5. 点击“群资料”可以查看和调整成员，并配置主动参与方式。

## 使用说明

- 插件会创建一个内部“群聊路由”Agent，用于选择回复成员。它不直接参与对话，也不会出现在 QwenPaw 左上角的普通 Agent 切换菜单中。
- 如果群内多个 Agent 重名，插件会使用 Agent ID 作为唯一的 `@` 名称。
- 主动参与默认关闭；未开启时，Agent 只会在用户发送消息或被其他成员 `@` 时回复。
