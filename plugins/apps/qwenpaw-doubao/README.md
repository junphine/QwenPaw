# 双虾汇 v2.4.3 - AI辩论平台

> 🦐 让AI智能体为你展开一场精彩辩论，小红书风格发言，人类担任裁判。智能体全列表显示、轮次扩至3-50轮、历史记录去重与空记录过滤。

## 📖 简介

**双虾汇**是一款AI辩论平台插件，让两个智能体围绕辩题进行多轮交锋，用户担任裁判判决胜负。

### 核心特色

- ✅ **小红书风格发言** - 分段清晰、emoji丰富、金句频出
- ✅ **真实智能体调用** - 调用系统内AI智能体进行真实对话
- ✅ **完整轮次管理** - 支持3-50轮辩论（常规3-20轮，超轮次21-50轮），自动推进
- ✅ **人类裁判机制** - 你来判决胜负，掌控全局
- ✅ **简洁优雅UI** - 卡片式布局，清晰直观

## 🚀 快速开始

### 安装

```bash
# 通过 QwenPaw 插件市场安装
qwenpaw plugin install qwenpaw-doubao

# 或手动安装
qwenpaw plugin install /path/to/qwenpaw-doubao
```

### 使用步骤

1. **选择辩手**
   - 从左侧列表选择**正方**智能体
   - 从右侧列表选择**反方**智能体
   - 注意：两个智能体不能相同

2. **选择辩题**
   - 从预设辩题中选择（如"内卷对社会发展是好事还是坏事？"）
   - 或选择"自定义"输入自己的辩题

3. **设置轮次**
   - 选择辩论轮次（3-5轮）
   - 轮次越多，辩论越深入

4. **开始辩论**
   - 点击"开始辩论"按钮
   - AI智能体将自动进行多轮交锋

5. **评判胜负**
   - 辩论结束后，点击"正方胜"、"反方胜"或"平局"
   - 查看判决结果和理由

## 🎨 小红书风格说明

智能体发言采用小红书风格，特点包括：

| 特点 | 说明 | 示例 |
|------|------|------|
| **分段清晰** | 每个论点单独成段，阅读舒适 | 每段一个核心观点 |
| **emoji点缀** | 适度使用emoji增加活力 | ✨ 💡 🎯 💭 🔥 |
| **金句开头** | 每段以金句总结开头 | "没有内卷，哪来的技术爆炸？" |
| **有理有据** | 引用数据、案例支撑论点 | "2023年中国GDP增速5.2%..." |
| **针对性强** | 回应对方观点，不自言自语 | "反方说内卷让人焦虑？我直接一个反驳！" |

### 发言结构

```
✨ 开篇金句：一句话总结核心观点

💡 核心论据1：第一个论点 + 数据/案例支撑

🎯 核心论据2：第二个论点 + 逻辑推演

💭 反驳回应：针对对方观点的具体反驳

🔥 小结升华：一句话升华立场
```

## 💡 使用技巧

### 智能体选择建议

- **选择不同特点的智能体**：辩论更精彩
- **正方**：选择逻辑性强、数据导向的智能体
- **反方**：选择批判性思维、风险意识强的智能体

### 辩题设计建议

- **有争议性**：双方都有话可说
- **有时效性**：结合当下热点
- **有明确立场**：避免过于模糊的辩题

### 轮次设置建议

- **3-10轮**：快速体验，适合初学者
- **11-20轮**：标准深度，适合常规讨论
- **21-50轮（超轮次）**：极限辩论，适合复杂议题深度交锋

### 历史记录使用

- **自动保存**：每场辩论结束后自动保存到本地历史
- **去重机制**：同一场辩论只保留最新记录，避免列表重复
- **空记录过滤**：自动过滤无效记录，列表保持整洁
- **一键恢复**：点击历史记录即可恢复完整辩论场景，包括正反方智能体
- **独立删除**：每条历史记录支持单独删除
